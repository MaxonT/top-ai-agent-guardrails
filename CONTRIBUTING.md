# Contributing to Top AI Agent Guardrails

This list is generated automatically from GitHub and refreshed on a schedule,
so edits to the README are overwritten by the next refresh. To change what it
contains, open an issue in this repository:

- **Suggest a project**: link it and say which section it belongs in.
- **Report an off-topic or dead entry**: link it and say why.

Accepted suggestions are recorded as relevance verdicts and take effect on the
next refresh. Ranking is always by GitHub stars; it cannot be bought or traded.

## 参与贡献（AI Agent 安全护栏大全）

本列表从 GitHub 自动生成并定时刷新，直接修改 README 会在下次刷新时被覆盖。
如需调整内容，请在本仓库提 issue：

- **推荐项目**：附上链接，并说明它属于哪个分区。
- **报告跑题或失效的条目**：附上链接并说明原因。

被采纳的建议会记录为相关性判断，在下次刷新时生效。排名始终按 GitHub Stars，不接受付费或交换。
